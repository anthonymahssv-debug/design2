# Contributing

1. Do not invent new brand hex values. Extend only through semantic aliases in `tokens/colors.css`.
2. Keep Spanish-first copy. Sentence case. No emoji.
3. Logo files in `assets/logos/` are official. Do not redraw the mark.
4. Open `index.html` after token changes.
5. Update `docs/DESIGN.md` when architecture or the PR plan changes.
